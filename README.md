# ギュッパ

押して、ためて、はなす。夜祭りの花火アクション。

ブラウザだけで遊べます（スマホ対応・インストール不要）。

## 遊び方

| 操作 | 何が起きるか |
|---|---|
| 押す（長押し） | 花火玉が「ボン」と打ち上がり、周りの鬼火を吸い寄せる |
| 離す | 花火が開き、範囲内の鬼火を巻き込む |
| 太鼓の拍に合わせて離す | ジャスト：範囲1.2倍・得点2倍（冠菊が開く） |
| ギリギリまで引きつける | 「際」：その鬼火の得点3倍 |

- 鬼火がコアに触れるか、コアの光が尽きると終演。
- 際どい撃破やジャストで「祭」ゲージがたまり、満タンでフィーバー。
- ための長さで花火が変わる（牡丹 → 菊 → 八重芯菊）。キーボードではスペースキーでも遊べます。

## 番付と履歴

- 終演後に名前を入れると、全国番付に載せられます。
- 「自分の記録」（この端末の上位10件）と「履歴」（最近50回）は、ブラウザ内に保存されます。

## 公開のしかた（GitHub Pages）

1. リポジトリの **Settings → Pages** を開く。
2. **Build and deployment** の Source を **Deploy from a branch**、Branch を **main** と **/ (root)** にして Save。
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます。

## 全国番付を有効にする（Supabase）

設定しなくてもゲームは動きます（番付はその端末の記録だけになります）。

1. [Supabase](https://supabase.com/) で無料のプロジェクトを作る。
2. 左メニューの **SQL Editor** で、`supabase/schema.sql` の中身を貼り付けて **Run**。
3. **Project Settings → API** から **Project URL** と **anon public** キーをコピー。
4. `config.js` の `supabaseUrl` と `supabaseAnonKey` に貼り付けてコミット。

anon キーは公開してよい鍵です。書き込みは `schema.sql` のルールで制限しています（名前は1〜12文字、遊んだ時間に対してありえない得点は拒否、変更・削除は不可、全体で1分120件まで）。ただしゲームはブラウザで動くため、得点の改ざんを完全には防げません。

## 開発

- ゲーム本体は `src/game.html`、花火の音は `src/sounds.json`（base64）。
- `python3 build.py` で `index.html` を組み立てます。`index.html` は直接編集しないでください。
- 手触りに関わる数値は `src/game.html` 冒頭の `P` にまとめてあります。
